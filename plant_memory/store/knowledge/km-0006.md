# Furnace draft instability from draft-control coupling

**Oscillating upper-furnace pressure (PT_8313A–F) with steady firing points to a draft-control loop / IDF coupling problem, not a combustion upset.**

When the six furnace-pressure points swing together while combustion is steady, the furnace-draft control loop and its IDF actuator are the suspects. Check loop tuning and IDF response per ctrl_furnace_draft_loop.

## Recommended corrective actions

1. Review furnace-draft loop tuning; check for IDF damper/VFD hunting.
2. Confirm PT_8313A–F sensors agree; a single outlier suggests a sensor fault instead.
